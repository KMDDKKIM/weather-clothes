## 2026-11-13 GitHub 저장소는 공개로 유지

- **결정**: `KMDDKKIM/weather-clothes` 저장소를 비공개로 바꾸지 않고 공개로 둔다.
- **이유**: 무료 계정에서는 비공개 저장소의 GitHub Pages가 꺼진다. 그러면 웹 앱(`kmddkkim.github.io/weather-clothes`)과 플레이 콘솔에 등록한 개인정보처리방침 주소가 함께 사라져 심사에 걸린다. 인증키 같은 비밀값은 중계 서버에만 있어 저장소에는 없다.
- **보류한 대안**: 비공개 + Cloudflare Pages로 사이트 이전(주소·방침 URL·앱 재빌드 필요), 사이트 전용 공개 저장소 분리, GitHub Pro(월 4달러).

## 2026-11-10 날씨 출처를 기상청·에어코리아로, 키는 중계 서버에

- **결정**: 기온·강수·바람은 기상청 단기예보, 미세먼지는 에어코리아. 자외선만 Open-Meteo. 실패하면 Open-Meteo로 대체.
- **이유**: 엄마들이 비교하는 네이버·기상청 날씨와 숫자가 같아야 믿고 쓴다. 미세먼지도 실측이 더 정확.
- 체감온도는 기상청 공식으로 보여주고, 옷을 고를 때만 월별 보정(예전 옷 기준과 맞춤, 1년 시뮬레이션으로 같은 옷 78~93%).
- 공공데이터포털 인증키는 앱에 넣지 않고 Cloudflare Workers 중계 서버(`weather-clothes-api.kmddkkim.workers.dev`)의 비밀값으로만. 같은 요청은 서버에 저장해 일일 트래픽 제한에 여유.
- **남은 일**: 사용자가 늘면 공공데이터포털 활용사례 등록 후 운영계정 신청(에어코리아 개발계정은 기능별 하루 500번).
