## 5. 앱 콘텐츠 설문 (답변 초안)

### 앱 액세스 권한
- 모든 기능을 로그인 없이 쓸 수 있음 → **"특별한 액세스 권한 없이 모든 기능 사용 가능"**

### 광고
- **광고 없음** (지금은 쇼핑 검색 링크만 있고, 광고 SDK나 광고 게재 없음)
- 나중에 제휴 광고를 붙이면 "광고 포함"으로 바꾸고 개인정보처리방침도 같이 고치기

### 타겟층 및 콘텐츠
- 대상 연령: **만 18세 이상만** 선택 (사용자는 부모)
- "아동에게 의도치 않게 어필할 수 있나요?" → 아니요 (부모용 날씨·옷차림 정보 앱)
- ⚠️ 아동 연령대를 고르면 "가족 정책" 심사가 추가로 붙으니 고르지 않기

### 콘텐츠 등급 (IARC 설문)
- 카테고리: 참고자료/뉴스/교육이 아닌 **"유틸리티, 생산성, 커뮤니케이션 또는 기타"**
- 폭력, 성적 콘텐츠, 욕설, 약물, 도박, 사용자 간 소통, 위치 공유(다른 사용자에게) → 모두 **아니요**
- 예상 결과: 전체이용가

### 데이터 보안 (Data safety)
> 구글 기준으로는 "개발자 서버"가 아니어도 **앱이 휴대폰 밖으로 보내는 데이터**는 수집으로 봐요.
> 이 앱은 날씨 조회를 위해 위치(격자·좌표)를 개발자 중계 서버(Cloudflare, 기록 안 함)를 거쳐 공공데이터포털(기상청·에어코리아)에, 그리고 Open-Meteo·OpenStreetMap에 보내므로 **위치를 "수집"으로 신고**하는 게 안전해요.

| 질문 | 답변 |
|---|---|
| 데이터를 수집하거나 공유하나요? | **예** |
| 전송 중 암호화되나요? | **예** (모든 요청이 https) |
| 데이터 삭제를 요청할 수 있나요? | 계정이 없고 개발자가 보관하는 데이터가 없음 → 앱 삭제/설정 초기화로 기기 안 데이터 삭제 (설명란에 적기) |

| 데이터 유형 | 수집 | 공유 | 필수/선택 | 목적 |
|---|---|---|---|---|
| 위치 > 대략적인 위치 | 예 | 아니요* | 선택 ("현재 위치" 버튼) | 앱 기능 |
| 위치 > 정확한 위치 | 예 | 아니요* | 선택 ("현재 위치" 버튼) | 앱 기능 |
| 앱 활동 > 앱 내 검색 기록 (동네 검색어) | 예 | 아니요* | 선택 | 앱 기능 |

\* 사용자가 직접 버튼을 눌러 날씨·동네를 조회하는 경우라 "공유" 예외(사용자가 시작한 전송)에 해당한다고 봤어요. 확신이 없으면 "공유: 예"로 신고해도 불이익은 없어요.
